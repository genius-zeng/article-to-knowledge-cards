# make-knowledge-cards

`make-knowledge-cards` 是一个 Codex Skill，用于把文章提炼成便于复习的知识卡片。

## 解决的问题

长文章通常混有背景、重复表述和次要细节，不易快速复习。本 Skill 从用户提供的内容中筛选真正重要且彼此独立的知识点，将其整理为简短、可自测的卡片；它不会补充原文没有的信息。

## 主要功能

- 接收用户粘贴的文章，或读取本地 `.md`、`.markdown`、`.txt` 文件。
- 通常生成 5–8 张卡片；原文的重要知识点不足时会输出更少的卡片，不会凑数。
- 每张卡片包含标题、核心知识、简明解释，以及原文案例或可由卡片回答的自测问题。
- 合并重复内容，并确保一张卡片只讲一个知识点。
- 默认保留原文语言；用户可另行指定输出语言。

不支持网页抓取、PDF、Anki 卡组或图形界面。

## 安装方法

将本项目中的 Skill 目录复制到 Codex 的 skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/make-knowledge-cards "${CODEX_HOME:-$HOME/.codex}/skills/"
```

安装完成后，在 Codex 中通过 `$make-knowledge-cards` 调用。若你的 Codex 已将本项目作为可发现的技能目录，也可以直接使用当前项目中的 `skills/make-knowledge-cards`，无需复制。

## 使用方法

### 粘贴文章

```text
使用 $make-knowledge-cards 将以下文章转换成知识卡片：
……文章正文……
```

### 使用本地文件

```text
使用 $make-knowledge-cards 读取 /绝对路径/文章.md，并转换成知识卡片。
```

文件必须是本地 `.md`、`.markdown` 或 `.txt` 文件。若内容是 PDF、网页或其他不支持格式，请先将正文转为文本后再使用。

## 输入输出示例

输入：

```text
番茄工作法把任务分成 25 分钟的专注时段，时段结束后休息 5 分钟。
完成四个时段后，可安排一次较长休息。
```

输出：

```markdown
### 卡片 1｜专注时段
**核心知识：** 番茄工作法以 25 分钟为一个专注时段。
**简明解释：** 工作被划分为固定长度的专注阶段。
**例子或自测：** 一个专注时段持续多久？

### 卡片 2｜短休息
**核心知识：** 每个专注时段结束后休息 5 分钟。
**简明解释：** 专注阶段与短暂休息交替进行。
**例子或自测：** 25 分钟专注结束后应休息多久？

### 卡片 3｜较长休息
**核心知识：** 完成四个专注时段后可安排一次较长休息。
**简明解释：** 较长休息安排在完成四个时段之后。
**例子或自测：** 较长休息在完成多少个专注时段后安排？
```

此示例只有三个独立知识点，因此只生成三张卡片。
